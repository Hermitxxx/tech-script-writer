# Scripted: Platform & Device UI Terminology Guide

Accurate UI terminology is essential for smooth voiceover pacing and viewer trust. Use the exact menu names and UI actions for each target platform.

---

## 1. Samsung Galaxy (One UI)

* **Settings App**: Always refer to as `Settings`.
* **Battery & Background Limits**:
  - `Settings` -> `Battery` -> `Background usage limits` -> `Sleeping apps` / `Never sleeping apps`.
* **App Management**:
  - `Settings` -> `Apps` -> Search or select app -> `Storage` -> `Clear cache` / `Clear data`.
  - Force stop: `Settings` -> `Apps` -> Select app -> `Force stop` -> `OK`.
* **Notifications**:
  - `Settings` -> `Notifications` -> `App notifications` -> Select app -> `Allow notifications`.
* **Sound & Vibration**:
  - `Settings` -> `Sounds and vibration` -> `Volume` -> Adjust `Media` / `Notifications` / `Alarm` slider.
* **Galaxy AI**:
  - `Settings` -> `Galaxy AI` -> `Process data only on device`.
* **Display**:
  - `Settings` -> `Display` -> `Motion smoothness` (Adaptive / Standard).

---

## 2. Xiaomi / Redmi (HyperOS / MIUI)

* **Control Center**:
  - Pull down from top right for Control Center; top left for Notification shade.
  - `Settings` -> `Notifications & Status Bar` -> `Control Center Style` (Classic vs New style).
* **System UI & Cache**:
  - `Settings` -> `Apps` -> `Manage apps` (or search directly) -> `System UI` -> `Storage` -> `Clear Cache`.
* **HyperOS Updates**:
  - `Settings` -> `About phone` -> Tap `HyperOS Version` -> `Check for updates`.
* **Storage & Cleaner**:
  - `Settings` -> `About phone` -> `Storage` -> `Free up storage`.
* **App Lock**:
  - `Settings` -> `Apps` -> `App lock`.

---

## 3. Google Pixel (Stock Android)

* **Display & Brightness**:
  - `Settings` -> `Display & touch` -> `Brightness level` / `Adaptive brightness`.
* **Battery**:
  - `Settings` -> `Battery` -> `Battery usage` / `Battery Saver`.
* **Security & Privacy**:
  - `Settings` -> `Security & privacy` -> `More security & privacy` -> `App pinning`.
* **App Info Quick Access**:
  - `Press and hold the [App] icon` -> `Tap App info (i icon)`.

---

## 4. Windows 11 & PC Apps

* **WhatsApp Web / WhatsApp PC**:
  - Settings: Click gear icon in bottom-left corner.
  - Linked Devices: `web.whatsapp.com` -> Phone WhatsApp -> Three dots -> `Linked Devices` -> `Link a Device`.
  - Inactive/Sleeping Tabs: Browser `Settings` -> `System and performance` -> `Never put these sites to sleep`.
* **Discord PC**:
  - Status Menu: Click user avatar at the bottom-left -> Select `Online`, `Idle`, `Do Not Disturb`, or `Invisible`.
  - Server Settings: Click server name dropdown at top of channel list -> `Server Settings`.
* **Google Chrome**:
  - Three-dot menu at top-right -> `Help` -> `About Google Chrome` (for auto-updates).
  - Clear Data: `Ctrl + Shift + Delete` -> Select time range -> `Clear data`.

---

## 5. macOS (e.g. Mac mini M4)

* **Apple Menu**: Always refer to as `"Open the Apple menu"` (top-left corner).
* **System Settings**: `Apple menu` -> `System Settings`.
* **Sound Output**: `System Settings` -> `Sound` -> Under `Output & Input`, click `Output` -> Select device.
* **Force Quit**: `Press Command + Option + Escape` -> Select app -> `Click Force Quit`.
* **Safe Mode Boot**: `Press and hold power button until "Loading startup options" appears` -> Select disk -> `Hold Shift` -> `Continue in Safe Mode`.
